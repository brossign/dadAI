# DadAI — An AI Assistant for New Dads

A supportive AI fine-tuned on real Reddit parenting conversations.
Responds with empathy, warmth, and practical wisdom — like a friend who's been through it all.

**Local model:** Mistral 7B Instruct v0.3 (4-bit MLX) + LoRA fine-tuning on 2,147 curated examples  
**This demo:** Mistral 7B via HF Inference API with enhanced system prompt
